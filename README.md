# 跨境业务场景运营系统 Demo

三个端、面向不同用户：

- **H5 端**（档口业主移动端）：线下批发档口老板用，手机上管理自己的商品——拍照上新、自动出图、一键发布。
- **项目企业端**（PC）：温州项目 + 南京项目功能合一的**入驻企业工作台**（商品经营、客户线索、询价报价、合规处理含境内/境外、订单履约、AI 内容工作台）。
- **跨境卖家端**（PC）：给**跨境电商卖家**用的独立工作台，只含卖家需要的功能（商品管理、AI 内容、全球获客、询价报价、海外合规、订单履约）。

## 在线访问

- H5 端（档口业主商品管理）：https://h5.visitworld.me
- 项目企业端（温州 + 南京入驻企业）：https://pc.visitworld.me
- 跨境卖家端（独立卖家）：https://seller.visitworld.me

三个端共用同一套业务对象与领域状态（`src/domain`），本地演示数据保存在各端 localStorage，损坏或关系不完整时恢复到确定性 fixtures。

## H5 端（档口业主 · 极简拍照出图，底部 3 Tab：首页 / 商品 / 我的）

给线下批发档口老板用，打开手机就是"拍照上新"：

- **首页**：大按钮「📷 拍照上新」+ **「✨ AI 商品内容工作台」入口**（嵌入极创系统）+ 我的商品大图卡片 + 待处理提醒
- **拍照上新（三步）**：拍照/选图 → **自动生成效果图**（商品主图 / 场景图 / 视频封面，可"换一张"重新生成，也可**去 AI 商品内容工作台生成真实效果**）→ 填名称/价格 → **一键创建并发布**
- **AI 商品内容工作台**（全屏嵌入 https://lkb-agent.demo.xyb2b.com）：服装套图、图片编辑、质量提升、视频创作、视频脚本复制、视频编辑等真实 AI 工具，首次使用在框内登录体验账号（郑聪体验 / zxcvbnm123），生成记录与素材库保存在极创系统内
- **商品**：我的商品大图网格（已发布 / 未发布筛选）
- **商品详情**：大图浏览、编辑名称价格、发布到商城、需处理提醒
- **待处理**：补充合规材料、确认新内容、完成任务（简单一句话 + 一个按钮）
- **商品素材（AI 联动）**：商品详情素材区可**导入 AI 生成图**（极创生成→保存相册→导入写回商品素材），并可直接去 AI 工作台生成商品图/视频；拍照上新出图步骤提供「从相册导入 AI 生成图」
- **我的**：档口信息、业务入口、PC 端入口、重置演示数据

老板视角不出现"候选结果、版本、合规案件"等企业术语，统一收敛为"待处理"提醒。

## 项目企业端（pc.visitworld.me · 温州 + 南京入驻企业）

温州项目与南京项目的能力合一的入驻企业工作台，**不含平台运营**（企业管理/服务商/项目配置/服务需求池/9810-9710-1039 均不做）：

- 工作台：待办任务、经营数据、功能模块入口、风险预警
- 商品管理：商品列表、商品工作台（候选内容确认、版本、合规、发布）
- 客户与线索：线索筛选、确认入库、分配、触达跟进、转商机
- 询价与报价：需求确认、商品匹配、报价方案、报价版本、客户反馈、转商机/订单
- 合规处理：案件、材料、风险、整改、复核、归档（境内 / 境外范围）
- 订单与履约：订单、履约节点、风险事件、库存入库
- AI 内容工作台（/lkb）：全屏嵌入「极创 · AI 商品内容工作台」，无外层壳

## 跨境卖家端（seller.visitworld.me · 亚马逊 / TikTok / 独立站 2C 卖家的 AI 工具）

**定位：不是经营管理系统**（订单、库存、销售等在卖家主业务系统中），而是为 2C 卖家提供的**基于 AI 的额外增值功能**：

- **AI 功能中心（首页）**：5 个 AI 工具入口 + 快速开始（选商品直达生成）
- **AI 生图 / 生视频**：全屏嵌入极创（商品图、场景图、短视频、A+ 内容）
- **AI 生成 Listing**：选商品 + 语言（英语/德语/日语/西班牙语）→ 按站点差异化生成亚马逊（标题/五点/关键词）、TikTok（脚本+标签）、独立站（标题/描述/特性），可编辑、复制、**一键保存到该平台 Listing**（写回商品）
- **AI 选品分析**：输入品类/关键词 + 目标站点 → 市场热度、趋势、季节性、竞争程度、机会评分、竞争结构与打法预算建议；**AI 已发现的机会**（6 个候选商品）可展开查看**市场与竞争、利润测算（售价/采购/头程/佣金/广告/净利/毛利率）、合规要求、试款预算与打法、可匹配货源**
- **AI 合规助手（法规合规中心）**：① 合规查询——按站点（亚马逊美国/欧洲、TikTok、独立站）× 类目查询强制认证、标签、包装环保、平台要求完整清单；② 商品诊断——对比商品已有认证，输出缺失项、风险等级与整改路径；③ HS 编码——商品智能归类建议；④ 合规问答——境内/境外高频问答知识库；⑤ 认证档案——商品认证状态与到期提醒
- **AI 广告助手**：选商品 + 平台 + 广告目标（新品推爆/稳定出单/清库存）→ 生成 **A/B/C 三套文案方案**（利益驱动/场景种草/信任背书）、**A/B 测试建议**（先测组合/周期/指标/判断标准）、**预算分配建议**（日预算/渠道分配/策略）与素材方向

> 订单发货、售后客服、库存补货、销售与利润等功能在卖家其他系统中已有，本 Demo 不重复建设。

## Demo 角色

- 档口业主（H5 端）：拍照上新、自动出图、一键发布；在"待处理"里补充材料、确认内容
- 入驻企业负责人（项目企业端）：确认关键结果、处理合规和查看经营数据
- 跨境卖家（卖家端）：经营自己的商品、内容、获客、报价、合规与订单
- 商品运营 / 服务商 / 采购商等角色：按领域权限处理各自业务

## 底层业务规则

- 商品、线索、询价、报价、合规案件、订单等是长期业务对象，不是一次性文档输出。
- 处理结果先作为候选结果，确认后才写回正式对象；写回校验组织、项目、角色、任务负责人和 source version，冲突不会静默覆盖。
- 正式写回生成版本、审计记录和下一步任务；失败候选保留并可重试。
- 草稿/待完善商品可直接编辑；进入内容处理后必须走「候选 → 确认/驳回 → 写回」。
- 商品合规由案件、风险、材料和复核共同决定；未完成时商品不能进入正常经营状态。
- 报价反馈与报价版本分开，修订会废弃旧版本但保留历史。
- 客户角色只能对「自己询价产生的报价」反馈（查看/接受/拒绝/议价），商家侧跟进任务与通知不挂在客户名下。

## 代码分层

- `src/domain/`：业务对象、fixtures、reducer、store、selectors（唯一业务状态入口）
- `src/components/`：PC 端公共壳与组件
- `src/pages/`：项目企业端页面（工作台、商品、线索、报价、合规、订单、AI 工作台嵌入）
- `src/seller/`：跨境卖家端（SellerApp/SellerShell/SellerHome，复用 `src/pages` 流程页）
- `src/h5/`：H5 端入口、App 风格壳、页面
- `src/styles/`：视觉变量、全局样式和 H5 样式
- `index.html` / `h5.html` / `seller.html`：三个构建入口

## Mock 与真实系统边界

当前 Demo 使用 fixtures、localStorage 和同步 reducer 模拟真实服务。真实版本可以保留同一业务契约，把 reducer 后面的本地状态服务替换为 API、数据库、文件存储、异步任务和外部连接适配器。外部数据源、渠道发布、真实文件处理、真实生成服务和实时跨端同步不属于本阶段实现范围。
